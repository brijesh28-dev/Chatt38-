# Chat38

Privacy-first, end-to-end encrypted messaging app for Android.

## 🔒 Features

- End-to-end encryption using Signal protocol
- Private connections (Bonds)
- Secure group chats
- Media sharing with encryption
- Push notifications with profile pictures

## 📥 Download

Download the latest version from [Releases](https://github.com/brijesh28-dev/Chatt38-/releases)

## 📱 Requirements

- Android 6.0 or higher
- 100MB storage space

## 🛡️ Privacy

Chat38 uses Signal-protocol encryption (X25519 + AES-256-GCM). Your messages are encrypted on your device and only you and your recipients can read them.
